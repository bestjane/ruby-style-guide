# 项目简报：聆思平台流程编排知识库 (Memory Bank)

## 1. 项目目标

本项目的核心目标是：**构建一个全面且结构化的，关于聆思平台（LSPlatform）流程编排功能的知识库（Memory Bank），使AI助手“Cline”能够深入理解这些功能，并有效地协助开发者进行使用。**

## 2. 项目范围

为了实现上述目标，您（Cline）需要掌握的知识和辅助能力将覆盖以下关键领域，**专注于端云一体化流程编排，特别是针对聆思大模型开发套件的应用**：

*   **聆思平台 (LSPlatform) 基础：**
    *   LSPlatform的核心概念。
    *   可视化流程编排界面（节点栏、编排区、辅助栏）的理解与使用。
    *   账户设置与API密钥管理。
*   **应用创建与管理：**
    *   应用的创建流程，特别是基于模板（如“大模型套件语音交互与识图模板”）创建应用。
    *   理解和分析默认的应用编排流程。
    *   将应用部署到测试环境和生产环境。
    *   应用共享与测试（通过Web应用链接或直接URL访问）。
    *   应用删除。
*   **设备集成 (针对大模型开发套件)：**
    *   LSPlatform上“产品 (Product)”概念的理解及其创建流程。
    *   将已编排的云端应用配置并关联到“产品”。
    *   从硬件设备获取唯一的设备ID (Chip ID)。
    *   将设备ID添加到“产品”的白名单中。
    *   通过二维码扫描或命令行方式在设备端写入“产品”凭证（产品ID和密钥ID）。
*   **流程自定义：**
    *   理解自定义默认流程的动机和方法。
    *   以集成自定义知识库为例，掌握具体步骤：
        *   在LSPlatform上创建知识库。
        *   上传相关文档（支持txt, doc, pdf格式）。
        *   设置文档分片策略。
        *   修改应用编排流程，使用“知识点检索”节点并配置其指向新建的知识库。
        *   部署并测试自定义后的流程。
*   **与Node-RED相关的概念解析：**
    *   将聆思平台的编排概念（节点、流程、消息）与Node-RED中的相似核心概念进行映射，帮助熟悉Node-RED的开发者理解。
*   **问题排查与后续学习：**
    *   了解与上述流程相关的常见问题及基本排查思路。
    *   熟悉可供开发者进一步学习的聆思官方文档和资源。

**Cline的最终目标：**
基于此知识库，您应该能够：
*   回答开发者关于聆思平台流程编排功能和操作步骤的具体问题。
*   清晰地解释核心概念和技术原理。
*   引导用户逐步完成特定任务，例如创建应用、集成设备、或使用知识库自定义流程。
*   针对流程编排中遇到的常见问题，提供初步的辅助排查建议。
